
# 🧠 Blockchain & Emerging Tech Course + Consultant Scraper  
### 📍 Blockchain Association Singapore – Summer 2024

This project was developed during my internship at **Blockchain Association Singapore (BAS)** to automate the extraction, cleaning, and organization of key data related to Singapore’s fintech and emerging tech ecosystem. It supported BAS in preparing for strategic outreach and presentations to consultants, educational institutions, and public-private partners (including a session with **Mercedes-Benz Singapore**).

## 🔍 Purpose

- **Map out the growth** of education offerings in AI, Blockchain, Web3, and Cybersecurity.
- **Build contact databases** for certified consultants from key accreditation bodies (e.g. TUV SUD, IMCS).
- **Monitor open and closed government tender requests** related to digital innovation and technology.

## ⚙️ Tech Stack

| Tool | Usage |
|------|-------|
| `Python` | Automation, scripting, data cleaning |
| `Selenium` | Interact with dynamic web pages |
| `BeautifulSoup` | Parse and extract HTML content |
| `Pandas` | Structure and analyze datasets |
| `Excel Power Query` | Clean, deduplicate, and format data for internal team use |

## 📊 Results

### 🎓 MySkillsFuture Courses (Singapore’s public course platform)
Scraped and cleaned data on 508 unique A.I., Blockchain, Web3, and Cybersecurity courses across major institutions (SMU, NUS, NTU, SUSS, SUTD), adjusting for delivery formats (on-site, hybrid, remote).

- 📚 508 **Unique A.I. Courses**
- 🔗 97 **Unique Blockchain Courses**
- 🔐 187 **Unique Cybersecurity Courses**
- 🌐 20 **Unique Web3 Courses**

### 👥 Consultant Contact Databases
- 📇 334 **IMCS-certified consultants** collected
- 📇 286 **TUV SUD-certified consultants** collected

### 🗂️ Government Tender Records
- 🟢 496 **Open Tender Requests** (as of July 23, 2024)
- 🔴 522 **Closed Tender Requests** (dating back to June 6, 2024)

## 🧼 Features

- ✅ Scrapes from 10+ dynamic JavaScript and HTML sources
- ✅ Handles duplicate entries, formats inconsistencies, and filters by course validity
- ✅ Structures data for non-technical team members to use in Excel
- ✅ Automates routine data gathering and turns manual work into a scalable pipeline
