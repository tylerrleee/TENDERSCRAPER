
#  Blockchain & Emerging Tech Course + Consultant Scraper  
### Blockchain Association Singapore – Summer 2024

This project is one of the projects developed during my internship at **Blockchain Association Singapore (BAS)** in Summer 2024, to automate the extraction, cleaning, and organization of key data related to Singapore’s fintech and emerging tech ecosystem. It supported BAS in preparing for strategic outreach and presentations to RMC/CMC consultants, the Monetary Authority of Singapore, and blockchain Partners (including a session with **Mercedes-Benz Acentrik**).

This scraper serves as a template/guideline for many other web extraction I did for the company.

##  Purpose

- **Map out the growth** of education offerings in AI, Blockchain, Web3, and Cybersecurity.
- **Build contact databases** for certified consultants from key accreditation bodies (e.g. TUV SUD, IMCS).
- **Monitor open and closed government tender requests** related to digital innovation and technology.

## Tech Stack

| Tool | Usage |
|------|-------|
| `Python` | Automation, scripting, data cleaning |
| `Selenium` | Interact with dynamic web pages |
| `BeautifulSoup` | Parse and extract HTML content |
| `Pandas` | Structure and analyze datasets |
| `Excel Power Query` | Clean, deduplicate, and format data for internal team use |


## Features

- Scrapes from 10+ dynamic JavaScript and HTML sources
- Handles duplicate entries, formats inconsistencies, and filters by course validity
- Structures data for non-technical team members to use in Excel
- Automates routine data gathering and turns manual work into a scalable pipeline

## Impact

- Helped increase BAS outreach email coverage by **38%**
- Boosted seminar conversion rate by **24%**
- Used in partner presentation with **Mercedes-Benz Singapore** and future government engagement decks
